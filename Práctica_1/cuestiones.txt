Apartado 3
Ejecuta el programa con distintos tipos de parámetros, sin parámetros, o con más de uno. ¿Qué sucede?

Si ejecutamos con varios parametros:

java LongitudPalabras perro gato sol
Las longitudes de las palabras son:
- perro (5 caracteres).
- gato (4 caracteres).
- sol (3 caracteres).

Palabras almacenadas: [perro, gato, sol]
Longitud de 'No_almacenada': -1

Estos parámetros se convierten en palabras se calculan su longitudes y se almacenan en el objeto LongitudPalabras.
El programa imprime estas longitudes, las palabras almacenadas y la longitud de una palabra específica ("No_almacenada" en este caso).

Si no pasamos ninguna palabra como parametro obtenemos lo siguiente:

java LongitudPalabras
Se espera al menos una palabra como parametro.
